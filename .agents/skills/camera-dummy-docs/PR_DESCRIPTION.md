카메라 사양 PDF를 재가공해 부서별 더미 문서와 평가용 정답을 만드는 `generate-camera-dummy-docs` 스킬을 추가합니다. 제품 기준 골드 → 문서별 변형 → PDF·XLSX·DOCX·CSV 순서와, 기본·중복·유사 제품을 분리하는 폴더 규칙을 정의합니다.

### 포함 내용

- `SKILL.md`와 참조 문서: R&D·BOM·펌웨어·품질·생산 이관의 5개 문서군, 현실적인 업무 연결, 골드 계약, 재사용 프롬프트
- Python 도구 3개: 원본 ZIP 목록·해시 작성, 데이터셋 구조·단위·분할·쌍 라벨 검증, 정규화 필드·분류·중복/유사·충돌 채점
- 회귀 테스트 8개: 경로 이탈, 단위 오류, 제품군 분할 누출, 누락 필드 환각, 빈 예측 등

문서 작성은 에이전트가 PDF·Word·스프레드시트 제작 도구로 수행합니다. 포함된 CLI는 목록 작성·검증·채점을 담당합니다. 검증기는 구조와 참조 계약을 확인하며, 렌더링 품질·실제 문서 값·엔지니어링 타당성은 별도 검증 대상으로 명시했습니다.

### 검증

- `uv run python scripts/check.py`: Ruff·포맷 검사 및 기존 backend 테스트 66개 통과 (테스트 프로세스의 프록시 환경변수를 해제한 로컬 환경)
- `uv run python -m unittest discover -s skills/generate-camera-dummy-docs/tests -v`: 8개 통과
- 로컬 합성 데이터셋: 제품 34개, 논리 문서 170종·파일 680개, 골드 필드 9,042개, 쌍 561개, 충돌 8건의 구조 검증 통과
- 정답 예측 자체 점검, 빈 예측, 잘못된 값·단위·환각 필드 점검 완료. 자체 점검 점수는 실제 파서/모델 성능이 아닙니다.

원본 PDF와 생성된 대용량 문서는 PR에 포함하지 않습니다. `main` 반영은 담당자 검토와 승인 후 진행해 주세요.
