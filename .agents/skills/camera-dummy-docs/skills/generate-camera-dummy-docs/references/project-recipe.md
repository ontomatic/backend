## 변형

같은 의미의 한/영 별칭, mm↔cm, W↔mW, 표/서술 비중 차이를 적용한다. 일부 D1의 무게와 D4의 IK 등급을 누락한다. 일부 D4의 IP67을 IP66으로 바꾸어 D1과의 충돌을 만든다. 소비전력 초과에 따른 불합격·재시험·이관 보류와, 재고 부족에 따른 보충 조치도 포함한다. 규칙·비율·시드를 명세에 기록한다. 같은 문서의 4형식에는 같은 변형을 적용한다.
