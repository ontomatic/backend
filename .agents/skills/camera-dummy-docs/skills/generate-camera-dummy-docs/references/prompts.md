# 실행 프롬프트

## 전체 제작

첨부 카메라 PDF ZIP으로 `$generate-camera-dummy-docs`를 사용해 파싱·분류·추출·충돌·중복 검사용 더미 데이터셋을 만들어줘.

원본은 유형과 사양 구조만 참고하고 가상 제조사·제품명·모델명·제품코드·핵심 사양을 재설계해. 제품 기준 골드 → 문서별 정답과 변형 → PDF·XLSX·DOCX·CSV 순서로 생성해. 원본 근거와 합성 정보를 구분해.

17개 원본 재현이면 기본 17개+이름 변경 중복 8개+해상도 변경 유사 9개로 총 34개 제품을 만들어. 제품당 요구사항·사양, BOM·변경 이력, 펌웨어·SBOM, 품질시험·인증 이력, 양산이관·생산계획의 5종을 4형식으로 총 680개 제공해. 입력 수가 다르면 실제 자료와 요청을 기준으로 계산해.

부서에서 쓸 법한 문서번호·개정·담당·검토·승인과 업무 이력을 넣어. BOM은 부품표, 릴리스는 버전표, 품질은 시료·조건·측정·판정·재검, 생산은 작업지시·자재 소요·수급·이관 체크리스트로 만들어. 불합격→NCR→재시험→이관 보류, 자재 부족→보충 후 착수를 연결해.

별칭·단위·표/서술 차이·누락·부서 간 불일치를 넣고 골드에 기록해. 제품 IP67과 문서 IP66을 별도 정답으로 관리해. 없는 값은 null로 두고 해상도와 유효화소, 질량과 가속도를 구분해.

기본 / 중복·유사 변형 / 정답·평가자료를 나누고 변형 안에서도 중복과 유사를 분리해. 제품 유형→문서 종류→4형식 순서로 정리해. 골드·쌍/충돌 라벨·제품군 단위 분할·manifest·자동 채점·안내를 포함해. 값·단위·위치·계산·업무 연결과 렌더링을 확인한 뒤 ZIP으로 제공해. 자체 점검 100%를 실제 모델 성능으로 표현하지 마.

## 현실감 보강

기존 데이터셋을 `$generate-camera-dummy-docs`로 보강해줘. 수량·폴더·문서군·형식과 실험 라벨 의도는 유지하고 부서별 양식과 업무 이력을 현실적으로 만들어. 항목표만 반복하지 말고 담당·개정·시료·이슈·재고·부적합·후속 조치를 연결해. 변경한 내용과 페이지·셀·행을 골드에 갱신하고 검증 후 ZIP으로 제공해.

## 폴더 정리만

`$generate-camera-dummy-docs`의 제품 유형→문서 종류→4형식 구조로 기존 자료를 정리해줘. 기본과 변형을 나누고 변형 안에서도 중복·유사를 분리해. 문서 내용은 유지하고 해시로 동일함을 확인해. manifest와 채점 상대 경로를 갱신한 뒤 ZIP으로 제공해.
