# 품질관리 D안 프롬프트 스킬

제품 데이터시트를 읽고, 품질관리 문서 10종을 제품군별로 분리해 `.hwpx`, `.docx`, `.xlsx`, `.pdf`로 만들도록 지시하는 독립형 프롬프트를 작성하는 스킬입니다.

## 사용 방법

1. `SKILL.md`를 Codex 스킬로 사용하거나 `새_실행_프롬프트.md`를 복사합니다.
2. 프롬프트의 `{{...}}` 입력 칸을 원본 파일, 제품군, 출력 위치로 채웁니다.
3. 원본 사양은 페이지·섹션까지 확인해 입력하고, 확인되지 않은 값은 추정하지 않습니다.
4. 생성 결과는 아래 검증기로 구조와 XLSX 헤더를 확인합니다.

`새_실행_프롬프트.md`는 10종 스키마와 결함 규칙을 자체 포함합니다. `references/`는 스킬과 검증기가 사용하는 기준 문서입니다.

## 파일 구성

- `SKILL.md`: 스킬 실행 지침.
- `새_실행_프롬프트.md`: 입력에 맞춰 채우는 실행 프롬프트.
- `references/qc_contract.md`: 10종 스키마와 결함 규칙.
- `references/d_style.md`: 출력 구조와 문서 표현 규칙.
- `examples/validate_output.py`: 결과 폴더·확장자·XLSX 헤더 검증기.
- `requirements.txt`: Python 의존성.
- `.gitignore`: 캐시와 생성 결과물 제외 설정.

## 결과 검증

이 폴더에서 다음 명령을 실행합니다. `결과폴더`는 제품군별 하위 폴더가 있는 경로로 바꿉니다.

```bash
python -m pip install -r requirements.txt
python examples/validate_output.py "결과폴더"
```

검증기는 폴더 구조, 파일 구성, XLSX 헤더와 기본 파일 형식을 검사합니다. 문서 간 값 일치와 원본 사양 근거는 별도로 대조해야 합니다. PDF/DOCX는 실제 렌더링으로 한글 표시를 확인하고, HWPX는 한컴오피스에서 열어 편집 가능 여부를 확인해야 합니다.
